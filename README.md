# Aristo

![aristo verified](./docs/badge.svg)
[![crate](https://img.shields.io/crates/v/aristo.svg)](https://crates.io/crates/aristo)
[![docs](https://docs.rs/aristo/badge.svg)](https://docs.rs/aristo)
[![license](https://img.shields.io/crates/l/aristo.svg)](./LICENSE)

Annotation SDK for **verified intent in code** — write a one-line claim above a function, hash it against the function body, classify the function's verification status, and surface drift before it ships. Open-source under MIT, parent company [Aretta](https://aretta.dev).

This repository is the **canonical Rust implementation** of Aristo: proc-macros, shared library, and the `aristo` CLI binary. Other-language SDKs (Python, Go, TypeScript, ...) live in sibling repos and shell out to this CLI for protocol logic — there is one source of truth.

The badge above is generated by `aristo badge --out=docs/badge.svg` on every push (CI uploads a fresh copy as a workflow artifact; the committed copy is the last-pushed snapshot). Tier labels are: **Aspirant** → **Apprentice** → **Adept** → **Ascendent** → **Areté** (the last gated on `verify="full"` + server-bound proof; the rest scale by `verified / total` × per-module coverage per the [badge tier scheme](./docs/decisions/badge-tier-scheme.md)).

## Install

CLI (for `aristo init`, `aristo stamp`, `aristo verify`, etc.):

```bash
cargo install aristo
```

Library (for projects using `#[aristo::intent]` / `#[aristo::assume]` annotations):

```bash
cargo add aristo
```

Both come from the same release; `cargo install` builds the binary, `cargo add` pulls the proc-macros into your crate.

## Quickstart

```bash
# 1. Bootstrap a Rust project for Aristo
cd my-project
aristo init

# 2. Add the proc-macro crate
cargo add aristo

# 3. Annotate a function — claim + verification method
#    src/lib.rs:
#
#    #[aristo::intent("add_one returns its input plus one", verify = "test")]
#    pub fn add_one(x: i32) -> i32 { x + 1 }

# 4. Stamp the index from source
aristo stamp

# 5. Inspect what landed
aristo status        # per-pipeline rate + tier
aristo list          # flat enumeration
aristo show fn add_one
```

For neural-backed verification (`verify = "neural"`), install the bundled skill for your coding agent:

```bash
aristo install-skills --agent claude-code   # also: cursor, codex, opencode, antigravity
```

Then invoke `/aristo-neural-verify` from inside the agent to drain the pending queue.

## Status

**v0.1.0** — first public release. Offline scope only (`init`, `stamp`, `lint`, `verify` neural, `critique`, `doc`, `graph`, `badge`, `rename`, `show`, `list`, `status`, `session`).

**Phase 2 (deferred, no firm date):** server-side commands (`auth`, `sync`, `unbind`, `suggestions`), paid `verify = "full"` (formal proof pipeline), `verify = "test"` (free-tier auto-test injection), `verify --audit-only` (cert-validation strict mode), `aristos:` server-bound renames.

Phase 0 design archive lives in the parent [`aretta-sdk/`](https://github.com/aretta-dev/aretta-sdk) repo (see `../docs/` from this directory if checked out as a sibling).

## Workspace layout

```
crates/
├── aristo/         meta-crate users add via `cargo add aristo`
├── aristo-core/    shared library: types, index format, B5b verification, language registry
├── aristo-macros/  proc-macros (#[aristo::intent], #[aristo::assume]) — intentionally thin
└── aristo-cli/     binary crate (the `aristo` CLI)
```

Each crate publishes independently to crates.io; the meta-crate `aristo` is what most users depend on.
